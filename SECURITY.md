# Security policy

## Supported version

Only the latest commit on the default branch is supported. The checkpoint and
all outputs remain research-only regardless of version.

## Reporting a vulnerability

Do not post credentials, private CGM records, participant information, or an
exploitable security report in a public issue. Use GitHub's private vulnerability
reporting feature in the repository Security tab. Include affected versions,
reproduction steps using synthetic data, likely impact, and any proposed fix.

This channel is for software and data-security problems. It is not monitored for
medical emergencies or clinical advice.
