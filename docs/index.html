Open-source · CGM representation learning · research only

Every glucose day has a shape. Give it a fingerprint.

GlucoTrace turns 24 hours of continuous glucose monitor readings into 128 numbers you can compare, search, and visualize. It's a small, readable Transformer that never fills in missing readings, and it's evaluated against tests written down before training.

Four commands to your first report

A CSV with timestamp,glucose goes in, in mg/dL or with --unit mmol/L. You get back a fingerprint, a similarity score, or a single HTML report that works offline and loads no scripts.

$ pip install glucotrace && glucotrace download-model
$ glucotrace encode my-day.csv            # 128-number fingerprint
$ glucotrace compare monday.csv tuesday.csv
$ glucotrace report my-day.csv --manifest corpus/manifest.json --output report.html

Built to be believed

Most health-ML demos only show their best number. GlucoTrace was built so you can check its claims yourself.

observed_mask · gap_age

Missing stays missing

Sensor gaps are tracked explicitly and never interpolated. A dropped reading can't pass for a real one.

sha-256 · participant-disjoint

No leakage by accident

Splits are made by participant and bound to checksummed manifests. The loader refuses splits that no longer match their data.

declared before training

Pre-registered tests

Thresholds, probes, and the number of candidates are fixed in writing first. Each test set is opened once.

511,372 parameters

Small enough to read

A three-layer Transformer that trains on a laptop CPU in minutes, with 66 tests and no hidden services.

Every protocol, including the failures

Each protocol was declared before its candidates were trained. The failures are published alongside the successes.

  1. 1.0first candidate

    Failed 3 of 5 checks and was not released

    The first full candidate collapsed on the declared checks. Its result is kept in the repository and the test set was retired.

  2. 1.1candidate 6

    Passed all 5 checks and was released

    A new untouched holdout of 69 days from 31 participants. The embedding is non-collapsed and stable under random gaps, 60-minute gaps, and 15-minute cadence.

  3. 1.2six candidates

    A useful negative result

    Added source-leakage and usefulness gates, and tried adversarial training. None passed the source gate, so the test set stays closed. The diagnosis: 278 of 281 Colas training days start at midnight. That tells protocol 1.3 what to fix.
