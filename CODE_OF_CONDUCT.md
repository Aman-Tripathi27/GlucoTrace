# Code of conduct

We want GlucoTrace collaboration to be rigorous, welcoming, and safe.

Contributors must communicate respectfully, critique ideas rather than people,
credit others' work, protect private information, and avoid harassment,
discrimination, intimidation, or sexualized conduct. Scientific disagreement is
welcome when it is specific, evidence-based, and civil.

Maintainers may edit or remove comments, issues, commits, or contributions that
violate these expectations and may temporarily or permanently restrict
participation. Report conduct concerns privately to the repository owner through
their GitHub profile rather than disclosing sensitive details in a public issue.

This code applies in repository spaces and when representing the project in
public spaces.
